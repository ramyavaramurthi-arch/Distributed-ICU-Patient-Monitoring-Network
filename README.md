# Distributed-ICU-Patient-Monitoring-Network
A real-time distributed ICU patient monitoring system designed to monitor multiple patients using embedded systems and CAN communication. The project integrates ADC, UART, and CAN protocols to collect, transmit, and exchange patient health parameters for reliable and continuous monitoring.

Introduction

The Distributed ICU Patient Monitoring Network is an embedded system project designed for monitoring patient health parameters.

Objectives

* Monitor patient health parameters.
* Collect sensor data.
* Support communication between monitoring modules.
* Improve patient monitoring.

Technologies Used

* Embedded C
* LPC21xx Microcontroller
* UART Communication
* CAN Communication
* I2C Communication
* MAX30102 Sensor

Project Files

* ADC Driver
* CAN Driver
* I2C Driver
* UART Driver
* MAX30102 Sensor Code
* SpO2 Monitoring Code
* Main Program

Applications

* ICU Patient Monitoring
* Healthcare Monitoring Systems
* Remote Patient Monitoring

Conclusion

This project demonstrates an embedded approach to distributed patient health monitoring using sensor interfaces and communication protocols.
